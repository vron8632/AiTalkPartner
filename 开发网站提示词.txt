Django 自己不会说 MySQL 的“方言”，需要装一个驱动：
mysqlclient（推荐，C 实现，快）：pip install mysqlclient
PyMySQL（纯 Python，慢点但好装）：pip install pymysql + 项目 __init__.py 里加 pymysql.install_as_MySQLdb()
驱动干的事：把 Python 代码翻译成 MySQL 网络协议，通过 TCP/IP 连到 3306 端口发过去。
